# Portal web SGT

## Descargar para integrar

**La carpeta [entregas](entregas/) conserva sus archivos y rutas.** Para quien ya tiene SGT, el paquete instalable sigue siendo [FIX-PORTAL-002.zip](entregas/FIX-PORTAL-002.zip?raw=true). No necesita descargar las fuentes de desarrollo.

## Organización del trabajo

| Carpeta | Qué representa | Estado |
|---|---|---|
| [desarrollo/formulario-vecinos/FIX-PORTAL-001](desarrollo/formulario-vecinos/FIX-PORTAL-001/) | Primera propuesta visual del formulario de Vecinos | Antecedente de diseño; no es la entrega vigente |
| [desarrollo/portal-completo/FIX-PORTAL-002](desarrollo/portal-completo/FIX-PORTAL-002/) | Portada, Vecinos, Presidentes, Seguimiento y tres temas | Fuentes de la entrega aprobada |
| [entregas](entregas/) | ZIP, archivos completos para reemplazo e instrucciones del destinatario | Distribución; sin cambios por esta reorganización |

En cada FIX se conservan sus fuentes, candidato e instrucciones. El FIX del portal completo también contiene su referencia, empaquetador y pruebas. No se han modificado el diseño publicado ni el funcionamiento para reorganizar estas carpetas.
