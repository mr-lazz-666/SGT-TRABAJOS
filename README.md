# SGT — Trabajos y mejoras

Repositorio de mejoras independientes para el Sistema de Gestión Territorial.

## Forma de trabajo

- El proyecto original se utiliza como referencia de arquitectura.
- Cada mejora se organiza en una carpeta independiente.
- Las entregas incluyen código completo e instrucciones de integración manual.
- Se conservan las funciones existentes del proyecto.
- No se publican credenciales ni datos personales.
